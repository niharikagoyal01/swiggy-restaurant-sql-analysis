# Swiggy Restaurant Data Analysis Using SQL

## Project Overview
This project analyzes Swiggy restaurant listing data using SQL and SQLite. It explores restaurant distribution, cuisine popularity, restaurant chains, ratings, pricing, and value for money.

## Dataset
- **Records:** 148,541 restaurant listings
- **Database:** SQLite
- **Tools:** DB Browser for SQLite and SQL

## Business Questions
1. How many restaurants are listed per city?
2. What are the most popular cuisines across India?
3. Which restaurant chains have the most branches?
4. Top 5 cities with highest average restaurant rating?
5. What is the average cost for two across cities?
6. Which cuisines have the highest average rating?
7. Restaurants with rating above 4.5 and more than 1000 ratings
8. Business insight — which city has best value for money?

## Methodology
SQL queries were used for grouping, counting, aggregation, filtering, sorting, and calculating average ratings and costs.

## Files Included
- `Swiggy_Restaurant_Analysis.sql` — SQL queries for all eight questions.
- `q1 restaurants by city.csv` — Restaurant counts by city.
- `q2 popular cuisines.csv` — Popular cuisines.
- `q3 restaurant chains.csv` — Restaurant chains by branch count.
- `q4 top cities rating.csv` — Top-rated cities.
- `q5 avg cost by city.csv` — Average cost by city.
- `q6 highest rated cuisines.csv` — Cuisine ratings.
- `q7 high rating restaurants.csv` — Highly rated restaurants.
- `q8 value for money.csv` — City-wise cost and rating comparisons.

## Business Objective
The goal is to identify patterns in restaurant locations, cuisine preferences, pricing, and ratings to support business comparisons and consumer decision-making.

## Conclusion
This project demonstrates practical SQL skills through a structured analysis of restaurant data and eight business questions.
